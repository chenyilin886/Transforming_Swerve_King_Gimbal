# LK4005 A1相对位置控制（无机械槽位修正）

拨盘任务只发送0xA1力矩命令，并使用其中的累计角度和速度反馈。
位置环、速度环继续使用 `Dial_PID_Config`，两个发弹挡位实时共用。

## 当前行为

- 首次收到有效A1反馈时，目标角度直接等于当前累计角度，上电不会主动转动。
- 单发仍在当前相对目标上增加40°，短脉冲释放后也会完成该目标。
- 连发仍按配置射频连续增加相对目标，释放当周期贴实际位置并制动。
- 停火后不再延时寻找最近槽位，无论等待多久都不会生成修正目标。
- `raw_override`退出后目标贴实际当前位置，不执行回位或对槽。
- 反馈中断恢复时以恢复后的当前位置建立新目标；保持的触发信号仍需先释放。

因此，断电时如果拨盘停在半槽位置，重新上电后软件会把这个位置当作新的相对原点。
后续每次单发仍相对增加40°，但软件不保证外部机械结构处于绝对槽位。

## A1反馈

A1单圈编码器相位仍折算为：

```text
a1_output_deg = raw_angle × 360 / 65536 / 10
```

该值范围为[0,36)°，现在仅写入 `Dial_Status.a1_output_deg` 供诊断，
不参与目标计算。控制实际使用 `accumulated_rad` 和 `velocity_rad`。

A1超过100ms未更新、累计角或速度不是有限数、电机离线、遥控离线或急停时，
控制器仍发送零力矩并禁止发弹。这些安全保护没有删除。

## 兼容字段

`Dial_Calibration` 结构和全局变量暂时保留，以免改变Watch路径和其他模块的数据布局。
下列字段均不再参与控制：

- `zero_output_deg`
- `home_tolerance_deg`
- `home_velocity_limit`
- `home_raw_limit`
- `home_settle_ms`
- `stop_align_delay_ms`

修改这些字段不会引起上电修正、停火对槽、限速或重新定位。

| Watch字段 | 当前含义 |
| --- | --- |
| `Dial_Status.a1_output_deg` | A1输出端单圈相位，仅作诊断 |
| `Dial_Status.feedback_angle` | 本次运行的输出端累计弧度 |
| `Dial_Status.target_angle` | 当前相对位置目标弧度 |
| `Dial_Status.home_error_deg` | 相对目标减累计反馈，单位度 |
| `Dial_Status.home_delta_deg` | 兼容字段，固定为0 |
| `Dial_Status.home_feedback_valid` | A1快照有效且100ms内更新 |
| `Dial_Status.slot_reference_valid` | 已建立当前A1累计角参考 |
| `Dial_Status.home_state` | 0=禁止，1=等A1，2=运动中，3=到达当前相对目标 |

## 发弹方式

- S1上/S2上：先提交40°单发，持续800ms后转线性连发。
- S1上/S2下：收到触发当周期直接线性连发，不补足短脉冲未转完的40°。
- 默认5Hz对应200°/秒，两挡位分别使用各自的 `auto_fire_hz`。
- 视觉在线且两侧摩擦轮在线时视觉独占；切换挡位或触发源需先释放再触发。
- 双环PID、输出限幅、卡弹反转和所有安全停机逻辑保持不变。

协议驱动仍提供通用0x92/0x94诊断API，但应用和拨盘控制不调用。
