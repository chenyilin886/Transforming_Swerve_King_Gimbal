# 双视觉挡位回归检查

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run_dual_vision.ps1`。
需要 PATH 中有 MinGW `g++`。脚本在临时目录生成并清理两组测试程序。

测试执行真实的 `ShootFSM.cpp`、`DialController.hpp` 和 `PID.cpp`，仅用
`stubs/` 替换时间、遥控器和电机 IO，不连接硬件。覆盖：

- 上上、上下挡位摩擦轮开启、视觉独占；`fire=0` 屏蔽 wheel，`vision_ready=0` 不影响拨盘仲裁。
- 视觉断连/恢复、任一摩擦轮离线后的触发源切换及等待释放。
- 切换配置保留单发目标，取消连发超前目标，等待释放且不重复触发。
- 上上单发转连发，上下首周期直接连发；视觉/拨轮/鼠标均不额外提交40°。
- 两套配置的视觉连发频率、手动拨轮阈值和幅度调速独立生效。
- 公共PID在线修改在两个挡位都生效，包括速度目标及力矩限幅。
- 上下短脉冲不补足40°，释放后立即保持当前位置；连发计数无首发偏移。
- Watch修改发弹模式要求先释放触发，非法模式禁止输出。
- 经过中位使用原配置并关闭摩擦轮，鼠标左键回退仍有效。
- 当前配置的 enabled/clear_pid、关闭功能、遥控器离线和急停优先于 fire。
- 任意A1相位上电均以当前位置建立目标，不产生启动修正或等待。
- 旧 `Dial_Calibration` 数值不参与控制；无效/陈旧A1、电机掉线时仍保持零输出。
- A1缓存超过100ms仍会失效；`raw_override`退出后目标贴当前实际位置。
- 停火后无论等待多久、跨多少圈，都不会生成自动对槽目标。
- 测试电机替身不提供0x92/0x94接口，确保拨盘控制只依赖A1。
- 连发首周期及后续周期斜率一致，跨多个输出圈持续线性增加；频率零值/无效值/上限。
- 连发释放当周期取消超前目标并制动；单发短脉冲仍完整执行40°。
- 单发短脉冲仍完成完整40°；停火后漂移由原相对位置目标保持，不进行槽位修正。
- 掉线恢复以恢复时位置建立新相对目标；解卡仍保留已提交目标。

`lk4005_protocol.cpp` 另执行真实 LK 驱动、MotorBase、StateWatch 和 CAN 接口，
验证 0x94 请求/响应、字节序、角度范围、A1 过零累计、快照、短帧/错误 ID 过滤，
以及位置查询和使能确认不会覆盖 A1 反馈或伪造运动在线状态。
0x92覆盖7字节有符号角度（正负值及56位边界）、单位换算、错误帧过滤、A1角度/速度快照配对及过期。

## LK4005 A1相对位置控制

见 [A1相对位置说明](lk4005_calibration.md)。控制器不再执行启动、停火或
`raw_override`退出后的机械槽位修正；A1单圈相位仅保留作诊断。

## Watch 调参

| 挡位 | 配置 | `Shoot_Status.dial_config_mode` |
| --- | --- | --- |
| S1上 S2上 | `Dial_Config_UpUp` | 1 |
| S1上 S2下 | `Dial_Config_UpDown` | 2 |
| 其他 | `Dial_Config` | 0 |

挡位配置中的触发参数独立存储。公共PID已移至 `Dial_PID_Config`，所有挡位每周期
直接读取同一份参数；原 `Dial_Config_UpUp.pos_kp` 等字段已移除，Watch请更新路径。
公共配置包含两环P/I/D、积分隔离、积分限幅、速度目标限幅和力矩限幅。
原PID数值保持：位置环41/0/12，速度环40/0/18。

| 上下挡位可调项 | 默认值 | 作用 |
| --- | --- | --- |
| `Dial_Config_UpDown.fire_mode` | `DIRECT_AUTO`（1） | 直接连发；0为单发转连发 |
| `Dial_Config_UpDown.auto_fire_hz` | 5 | 固定射频，5Hz对应目标200°/秒 |
| `Dial_Config_UpDown.wheel_to_hz` | 0 | 0使用固定射频；大于0时为拨轮幅度调速最大射频 |
| `Dial_Config_UpDown.wheel_start_threshold` | 0.5 | 手动拨轮启动阈值 |

上下挡位忽略 `long_press_ms`，从检测到开火的第一周期起线性推进目标；
5Hz、4ms周期时首周期及后续周期都增加0.8°。持续100ms只规划20°，释放后不补足40°。
上上挡位 `fire_mode=SINGLE_THEN_AUTO`（0），保留40°单发及 `long_press_ms=800`。
`auto_fire_hz` 在视觉/手动下有效，频率上限50Hz；非正或非有限射频不推进连发目标。
Watch可在线调整；断电保存需修改 `Application/Variable.cpp` 对应初值并编译下载。

拨轮阈值和 `wheel_to_hz` 只影响手动拨轮。视觉在线且两侧摩擦轮在线时，视觉独占拨盘，
不额外检查 ready 或转速到位。`Shoot_Status.vision_control=1` 表示该独占状态。
`trigger_source` 为实际接受的触发：0=无，1=wheel，2=fire，3=鼠标左键。
`waiting_release=1` 时先释放当前选中信号，再重新触发；切换挡位、发弹模式或触发源时会置位。
首次启动只要收到新鲜A1坐标即可接受拨轮，不要求先静止、修正到位或先松开拨轮。
安全失能或反馈中断后的恢复仍要求释放一次，防止保持触发时意外重启。
`Dial_Calibration` 整体仅为现有Watch布局兼容保留，修改其中任意字段均不影响拨盘控制。

云台瞄准另要求 `vision_ready`，变形和急停优先。视觉实际接管时使用视觉 PID
和 Yaw 编码器速度反馈；退出时恢复手动参数并贴合反馈目标，不覆盖变形规划目标。
S2 经过中位被采样到时会执行原有中位模式，不延迟保留摩擦轮或视觉。

## 实机验证范围

主机测试不覆盖真实 CAN、IMU、USB 时序或机械运动。固件编译通过后，仍需实机
确认两挡位瞄准、视觉丢失后的手动接管、PID/反馈源恢复、变形优先，以及供弹频率。
本测试不烧录固件。
